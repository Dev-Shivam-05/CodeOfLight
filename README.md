## 🪔 The Inspiration

Diwali, the "Festival of Lights," is a celebration of the victory of light over darkness, good over evil, and knowledge over ignorance. In a world that is increasingly digital, how can we bring this warmth and tradition into the applications we use every day?

**Code of Light** is the answer to that question. It was born from a desire to infuse a touch of festive magic into a standard web function—the login. Instead of a cold, impersonal authentication, this project aims to make users smile by sharing the joy of Diwali, one line of code at a time. It's a small reminder that technology can, and should, be human-centric and celebratory.

## 🌟 Features Showcase

This isn't just a login page; it's a carefully crafted experience.

<details>
  <summary><strong>🔮 Glassmorphism & Aurora UI</strong></summary>
  <br>
  <p>The user interface is built on the principles of <strong>Glassmorphism</strong>, creating a frosted-glass effect that feels modern and tactile. This is layered over a dynamic, animated <strong>Aurora background</strong>, where shimmering colors shift and flow like the Northern Lights, providing a mesmerizing and premium visual foundation.</p>
</details>

<details>
  <summary><strong>✨ Interactive Particle Effects</strong></summary>
  <br>
  <p>The background isn't static. It's a living canvas of particles that subtly react and move, creating an enchanting atmosphere. This effect, built with pure CSS and JavaScript, ensures the page feels alive and engaging from the moment it loads.</p>
</details>

<details>
  <summary><strong>🎉 Dynamic Festive Greeting</strong></summary>
  <br>
  <p>The core functionality! Upon successful login, the application doesn't just redirect to a dashboard. It presents a full-screen, beautifully styled "Happy Diwali" message. This immediate, positive feedback turns a mundane task into a moment of celebration.</p>
</details>

<details>
  <summary><strong>📱 Flawlessly Responsive Design</strong></summary>
  <br>
  <p>Whether you're on a 4K monitor or a mobile phone, the experience remains seamless. The layout, animations, and typography are all built with a mobile-first approach, ensuring the magic of the festival is accessible on any device.</p>
</details>

## ⚙️ Local Setup Guide

Want to run this project on your own machine? Follow these simple steps.

1.  **Clone the Repository**
    ```bash

    git clone https://github.com/Dev-Shivam-05/[your-repo-name].git
    ```

2.  **Navigate to the Directory**
    ```bash
    # Move into the newly created project folder
    cd [your-repo-name]
    ```

3.  **Launch the Project**
    *   Simply open the `index.html` file in your favorite web browser.
